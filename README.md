# ForgeKit

ForgeKit is an open-source Java developer toolkit built as a long-term learning project to master Apache Maven.

## Project Goals

- Learn Apache Maven from first principles
- Build a modular Java project
- Understand multi-module builds, dependency management, plugins, and publishing
- Follow clean architecture and professional project structure

## Modules

- forgekit-core
- forgekit-text *(planned)*
- forgekit-file *(planned)*
- forgekit-json *(planned)*
- forgekit-cli *(planned)*

> The primary objective of this project is learning Maven. The application serves as a realistic vehicle for exploring Maven concepts incrementally.
